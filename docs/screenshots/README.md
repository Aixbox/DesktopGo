# Screenshots

根目录 [`README.md`](../../README.md) 和 [`README.en.md`](../../README.en.md) 目前直接渲染这里的 SVG 占位图：

- `launchpad-main.svg`
- `search-panel.svg`
- `settings-overview.svg`

后续如果要替换成真实截图，有两种方式：

1. 直接保留同名文件，把 SVG 内容替换成真实导出的 SVG
2. 新增 PNG 文件，再把 README 里的 `src` 路径改成对应的 PNG

建议：

- 优先统一宽高比例，避免 README 版式跳动
- 主界面建议使用宽图，搜索页和设置页建议使用半宽图
- 如果需要演示动效，可额外补一个 `launchpad-demo.gif`
