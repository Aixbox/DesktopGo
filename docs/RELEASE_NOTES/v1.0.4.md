# DesktopGo v1.0.4 ✨

`v1.0.4` 聚焦启动台稳定性、常驻窗口体验和开发环境隔离，重点补上 Windows 常驻场景下的材质、主题同步和数据污染问题。

## 新功能 🚀

- 新增窗口常驻能力，支持主窗口置顶状态同步。
- 当启用原生亚克力且窗口常驻时，主窗口会自动切换到更稳定的 Mica 背景路径。
- 补充导入模式下的拖拽导入流程，支持把程序、文件夹、文件和快捷方式直接拖进窗口。

## 修复与优化 🛠️

- 修正主窗口在深色 / 浅色切换时需要重新聚焦才会完整刷新的问题，设置页修改后会立即同步到 Launchpad 主窗口。
- 优化图标布局重置与布局修复逻辑，降低异常分页和单格页布局残留的问题。
- 更新图标管理与窗口常驻配套交互，减少主窗口返回和关闭时的状态错位。
- 优化常驻窗口下的材质观感，降低失焦后背景表现不稳定的问题。

## 工程与发布 📦

- 开发版与安装版现在会使用独立的数据 profile。
- 设置、布局数据库、图标快照、搜索日志和 Everything SDK 缓存不再共享，避免开发调试污染正式安装版数据。
- 本次发布已同步更新应用版本号、官网版本信息和发布说明文件，满足现有 GitHub Actions 发布流程要求。
