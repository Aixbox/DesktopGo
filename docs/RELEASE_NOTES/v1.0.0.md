# DesktopGo v1.0.0 🎉

DesktopGo 的首个 `1.0.0` 正式版。

这一版延续了前序公开版本的交互形态与能力边界，但把发布链路、版本元数据和对外说明统一整理到正式版本标准，适合作为后续持续迭代与应用内更新的稳定基线。

## ✨ 本次发布重点

### 🧭 启动台与桌面整理

- 支持通过全局快捷键快速呼出启动台。
- 支持托盘常驻、失焦自动隐藏与多种窗口模式切换。
- 支持桌面图标读取、拖拽排序、分页整理、文件夹和 Dock 固定。
- 支持 `customapp` 自定义应用目录，用于补充桌面之外的常用入口。

### 🔎 文件搜索

- 集成已安装版 Everything 的文件搜索能力。
- 支持搜索历史、筛选器、排序和键盘导航。
- 支持结果预览与大结果集场景下的按需加载。

### ⚙️ 设置、诊断与更新

- 提供主题、图标尺寸、标题行数、搜索行为与快捷键配置。
- 提供关于页、问题反馈入口与发布入口，方便定位当前构建信息。
- 发布流程会生成带签名的更新产物，并继续沿用 GitHub Releases 作为更新通道。

## 📦 安装与升级说明

- 当前仅支持 Windows 10 / 11。
- 文件搜索依赖已安装版 Everything；如果系统尚未安装，可在安装 DesktopGo 时一并安装。
- 建议优先使用 Release 附件中的安装器，不要直接使用源码压缩包。

## ⚠️ 已知限制

- 当前仅支持 Windows，不提供 macOS 或 Linux 构建。
- 文件搜索目前仅支持已安装版 Everything，不提供内置索引器。
- `customapp` 目录当前仅扫描一级目录。

## 🚀 后续版本基线

`v1.0.0` 之后的版本会继续沿用当前的版本号、发布说明和 GitHub Releases 更新链路约定，方便在应用内直接检查和安装后续更新。
