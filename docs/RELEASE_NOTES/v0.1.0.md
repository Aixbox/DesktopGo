# DesktopGo v0.1.0

DesktopGo 的第一个公开版本。

这一版聚焦于把 Windows 桌面应用启动、图标整理和文件搜索整合到一个统一入口中，让常用应用和常用文件都能更快被找到、整理和打开。

## 🚀 首发内容

### 🧭 启动台入口

- 支持使用 `Ctrl + Space` 快速呼出启动台。
- 支持托盘常驻，点击托盘图标可重新显示主界面。
- 主窗口支持失焦自动隐藏，适合快速唤起和快速关闭。
- 提供全屏、大、中、小四种窗口模式。

### 🗂️ 图标整理

- 读取并展示桌面图标，支持图标尺寸和标题行数调整。
- 支持拖拽排序、分页整理和跨页移动。
- 支持创建文件夹、打开文件夹、重命名文件夹。
- 支持 Dock 栏停靠，方便固定常用应用。
- 支持批量选择、隐藏和删除图标。
- 图标布局和相关设置会保存在本地，并支持一键重置布局。
- 支持 `customapp` 自定义图标来源，便于补充桌面之外的常用入口。

### 🔎 文件搜索

- 接入基于 Everything 的文件搜索能力。
- 支持搜索历史、筛选、排序和键盘导航。
- 支持结果预览，便于在打开前快速确认内容。
- 支持虚拟滚动和按需加载，在大结果集下也能保持可用体验。

### ⚙️ 设置与信息

- 提供主题、图标大小、标题行数、Dock 显示和搜索行为配置。
- 提供关于页，可直接查看版本号、应用标识、运行时信息以及项目入口。
- 已接入 GitHub Releases 更新链路，为后续版本提供应用内更新能力。

## 📦 安装与使用前提

- 当前版本仅支持 Windows。
- 文件搜索依赖已安装版 Everything；如果系统中未安装，可在 DesktopGo 安装过程中一并安装。
- `customapp` 目录支持自定义，但当前仅扫描一级目录。

## ⚠️ 当前限制

- 搜索能力目前仅支持已安装版 Everything，不提供独立的内置文件索引。
- 应用内更新能力已经接入，但实际升级体验会从后续发布版本开始体现。
- 当前版本重点覆盖桌面图标与 `customapp` 两类入口，其他来源仍会在后续版本继续补充。
