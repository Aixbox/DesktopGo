# DesktopGo v1.0.6 🎉

`v1.0.6` 聚焦 **壁纸体验**、**应用发现** 与 **视觉细节** 三条主线：新增内置精选壁纸库与背景原图管理，全面接入注册应用与 Windows 商店应用，并引入全局连续曲率圆角体系。

## 新功能 🚀

- **内置精选壁纸库**：设置中新增精选壁纸画廊，预置晴空云海、星夜营地、青苹果星球、二次元少女、草原暮色、海滨列车六张精选壁纸，一键应用、离线可用；支持背景原图管理与自定义壁纸默认蒙版浓度调整（本次默认浓度改为 0，画面更通透）。
- **应用发现全面增强**：新增 Windows 平台应用扫描与批量导入，目录扫描补充注册表注册应用来源；支持 Windows 商店应用（UWP/MSIX），启动台可覆盖到更多系统内应用。
- **全局连续曲率圆角**：窗口轮廓与图标圆角升级为超椭圆（squircle）连续曲率形状，过渡更自然，并统一缩放补偿，DPI 切换不再变形。
- **外观设置扩展**：新增前景色调与图标标题颜色设置选项，浅色壁纸上也能保持文字可读。
- **AI 图标分类管理**：内置图标分类条目支持删除与恢复，分类列表可按需精简。
- **安装器改进**：安装完成页新增开机自启动复选框，装完即选、无需进设置。
- **启动台细节**：背景模糊新增边缘渐隐处理，取景层过渡更柔和。

## 修复与优化 🛠️

- 拆分 Launchpad 大型组件与 Rust 侧 `build_app` 函数，持续满足千行文件与函数预算门禁，降低后续维护成本。

本次发布已同步更新应用版本号（package.json / tauri.conf.json / Cargo.toml / Cargo.lock）与发布说明文件，满足现有 GitHub Actions 发布流程要求。
