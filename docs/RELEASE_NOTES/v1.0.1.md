# DesktopGo v1.0.1 🛠️

`v1.0.1` 是一次围绕稳定性、搜索体验与主窗口视觉表现持续打磨的补丁更新。除修复图标管理、桌面特殊项识别和布局追加行为外，也补充了窗口模式、搜索运行状态提示，以及主启动台的主题风格配置能力。

## 本次更新 🔧

### 图标管理与桌面特殊项 🖼️

- 修复部分 Windows 桌面特殊项无法识别的问题，补齐回收站、此电脑、用户文件、网络、控制面板等项目的处理逻辑。
- 修复上述特殊项缺少图标或无法正常启动的问题。
- 修正特殊桌面项的同步条件，仅在系统桌面实际存在并启用时才进入图标快照。
- 修正应用重启时误触发图标刷新问题。现在只有在“设置 -> 图标管理”中手动刷新时，才会同步相关图标状态。
- 修复图标对账成功提示缺少删除数量的问题，结果反馈现在会显示新增、删除和总数。

### 布局与追加行为 📐

- 修复刷新后新增图标优先补前方空位的问题。
- 现在新增图标会默认追加到当前布局尾部，更符合已有使用习惯。

### 搜索运行状态与面板体验 🔎

- 为 Everything 运行时增加初始化状态检测；当 Everything 已启动但索引仍在准备时，界面会显示初始化提示，避免误判为搜索失败。
- 优化搜索面板的玻璃层次、结构布局与预览区域细节，提升主启动台中的搜索观感与可读性。

### 主窗口模式与视觉材质 🪟

- 新增主题风格切换，支持 `柔光玻璃` 与 `亚克力` 两种主启动台视觉材质。

### 交互与界面细节 🎛️

- 调整系统托盘相关交互与窗口控制逻辑，减少显示/隐藏过程中的异常行为。
- 优化部分搜索与设置界面的交互细节和稳定性。
