# DesktopGo v1.0.1 🛠️

`v1.0.1` 是一次以问题修复和行为校正为主的补丁版本，重点修正图标管理、桌面特殊项识别、布局追加行为，以及部分交互细节。

## 本次修复 🔧

### 图标管理与桌面特殊项 🖼️

- 修复部分 Windows 桌面特殊项无法识别的问题，补齐回收站、此电脑、用户文件、网络、控制面板等项目的处理逻辑。
- 修复上述特殊项缺少图标或无法正常启动的问题。
- 修正特殊桌面项的同步条件，仅在系统桌面实际存在并启用时才进入图标快照。
- 修正应用重启时误触发图标刷新问题。现在只有在“设置 -> 图标管理”中手动刷新时，才会同步相关图标状态。
- 修复图标对账成功提示缺少删除数量的问题，结果反馈现在会显示新增、删除和总数。

### 布局与追加行为 📐

- 修复刷新后新增图标优先补前方空位的问题。
- 现在新增图标会默认追加到当前布局尾部，更符合已有使用习惯。

### 交互与界面细节 🎛️

- 调整系统托盘相关交互与窗口控制逻辑，减少显示/隐藏过程中的异常行为。
- 优化部分搜索与设置界面的交互细节和稳定性。
