# DesktopGo v1.0.7 🎉

`v1.0.7` 聚焦 **托盘交互**、**窗口唤起** 与 **自动更新** 三条主线：新增托盘图标点击唤起启动台，重构 Windows 前台激活链路，并引入启动时自动检查更新，让桌面启动器更"随手可得"。

## 新功能 🚀

- **托盘图标点击唤起**：点击任务栏托盘图标即可直接打开启动台，支持溢出区定位与 `UI Automation` 精准命中按钮，避免误点展开箭头；单击/双击策略可按系统托盘行为自适应。
- **启动行为优化**：手动启动应用时直接打开启动台，开机自启动则保持静默，两种场景各得其所。
- **自动检查更新**：应用启动时自动检查新版本，配合发布转正脚本修复更新下载 URL 404 问题，应用内升级链路更可靠。
- **快捷导入增强**：扫描结果标记系统自带工具并默认隐藏弹窗，减少导入噪音。

## 修复与优化 🛠️

- **窗口前台切换重构**：新增窗口激活命令，改进 Windows 平台应用唤起逻辑，前台切换更稳定。
- **快捷导入修复**：修复漏网的系统组件未被按类过滤的问题，导入结果更干净。
- **AI 会话体验**：会话回复顶部新增实时计时，OpenAI 推理摘要增强；整理结果实现全覆盖并从首页重排布局。
- **安装器优化**：NSIS 静默卸载时逐文件删除应用数据，输出更清晰。
- **发布流程**：新增 finalize-release 工作流，测试构建转正后一键修复 latest.json 下载地址。

本次发布已同步更新应用版本号（package.json / tauri.conf.json / Cargo.toml / Cargo.lock）与发布说明文件，满足现有 GitHub Actions 发布流程要求。
