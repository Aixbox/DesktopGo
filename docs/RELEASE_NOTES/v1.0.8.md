# DesktopGo v1.0.8 🎉

`v1.0.8` 聚焦 **单实例管理**、**UI 细节优化** 与 **代码质量保障**：新增单实例支持防止多进程启动，修复图标网格勾选圆角显示问题，并引入 Husky pre-commit hook 确保代码质量，让桌面启动器更稳定、更精致。

## 新功能 🚀

- **单实例支持**：添加 `tauri-plugin-single-instance` 插件，确保应用只运行一个实例。当用户尝试启动第二个实例时，会自动唤起已运行的主窗口，而不是创建新进程，避免资源浪费和混淆。
- **代码质量保障**：引入 Husky pre-commit hook，在每次提交前自动运行测试和 Rust clippy 检查，确保代码质量符合 CI 标准，提前发现问题。

## 修复与优化 🛠️

- **图标网格勾选圆角修复**：调整图标网格中勾选圆角的位置和大小，使其与 Dock 栏保持一致。位置从距边缘 8px 调整到 2px，大小从 20px 缩小到 16px，并添加 z-50 确保始终显示在最顶层，不被相邻图标遮挡。
- **代码重构**：将插件注册逻辑提取到 `with_core_plugins` 函数，符合 clippy 行数限制；修复 clippy::let_unit_value 警告，提升代码质量。

本次发布已同步更新应用版本号（package.json / tauri.conf.json / Cargo.toml）与发布说明文件，满足现有 GitHub Actions 发布流程要求。
