# DesktopGo v1.0.2 🩹

`v1.0.2` 是一次面向稳定性与一致性的补丁更新，重点收敛主启动台在全屏显示、主题同步和布局重置上的几个高频问题，同时补强 Windows 环境下的显示与运行健壮性。

## 本次更新 🔧

### 主窗口显示与交互稳定性 🪟

- 优化启动台窗口的显示、激活与失焦保护逻辑，减少全屏或大窗口模式下的异常闪烁、误隐藏和显示不完整问题。
- 补充拖拽阶段的 pointer capture 控制，避免点击、拖拽和窗口切换之间的事件串扰影响主窗口交互体验。
- 增强多显示器环境下的窗口边界计算，改善不同屏幕布局中的启动台显示稳定性。

### 主题风格与亚克力同步 🎨

- 修复 `亚克力` 风格下系统主题变化后，窗口材质与应用内组件深浅色不同步的问题。
- 调整主题同步策略：在原生亚克力模式下，应用主题会跟随 Windows 当前深浅色，避免出现“亚克力变了但页面没变”的割裂感。

### 图标布局与重置行为 🧩

- 修复“设置 -> 图标管理 -> 重置图标”后，当前已打开的启动台仍沿用旧布局缓存的问题。
- 现在重置布局会强制重新读取持久化排布，文件夹、宫格排序与 Dock 状态都会立即恢复到默认布局。

### Windows 集成与搜索运行环境 ⚙️

- 改进开机自启在部分开发环境和 Windows 场景下的稳定性。
- 补强 Everything SDK 资源路径解析与不可用时的错误处理，降低搜索运行环境异常带来的失败概率。

### 工程与发布流程 🧪

- 为主题同步、拖拽 pointer capture 和布局重置策略补充自动化测试。
- 更新发布工作流的元数据校验逻辑，发布时会校验版本号一致性，并强制要求对应版本的发布说明文件存在。
