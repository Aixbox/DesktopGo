# DesktopGo v1.0.9 🎉

`v1.0.9` 聚焦 **桌面拖动体验**、**图标布局动效** 与 **应用内更新**：让图标和文件夹的移动更跟手、更有层次，并提升更新提示与下载链路的连续性。

## 新功能 🚀

- **物理拖动反馈**：图标拖动会根据指针速度产生轻微倾斜、挤压与拉伸，并在松手后自然回弹，保持跟手响应。
- **多格文件夹落位预览**：拖动文件夹时显示完整网格占位边界，结合背景模糊与布局缩放反馈，帮助准确判断落点。
- **动态布局重排**：图标、文件夹和 Dock 的让位与归位使用统一的弹性节奏，连续换位时保持运动衔接，减少跳动与闪烁。
- **应用内更新提示**：启动时保留更新状态，并在桌面入口提供可见的更新提示，便于直接进入更新页面。

## 修复与优化 🛠️

- 修复文件夹拖动落位后的坐标偏移，确保视觉位置与实际网格位置一致。
- 优化多选拖动、滚动自动跟随和文件夹折叠后的图标位置保持。
- 增强编辑模式下的悬停、按压、阴影和悬浮层次反馈。
- 将拖动与重排动效收敛到统一的运动语言，并支持减少动态效果偏好。

本次发布已同步更新应用版本号（package.json / tauri.conf.json / Cargo.toml / Cargo.lock）与发布说明文件，满足现有 GitHub Actions 发布流程要求。
