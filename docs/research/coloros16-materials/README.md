## 最重要的结论

1. ColorOS 没有一个可以无条件复用到所有表面的“统一柔雾配方”。
2. Launcher 文件夹完整深色材质是 MIX → OVERLAY；SystemUI 普通通知使用面板与卡片两组配方，包含 LUMINOSITY，能明显收敛背景亮度。
3. 普通应用图标的深黑底图、COUI 黑底卡片、文件夹普通黑色回退层都属于不同路径。
4. top/bottom layer 是混色层名称，不是固定纵向渐变；高光描边有条件，不能默认添加常驻白框。
5. 分析时 DesktopGo 在原生混色后附加的浅色雾色和纵向渐变已移除；当前浅色改为模糊壁纸与半透明浅灰直接混合，不叠加原生配方。共享纹理、32 CSS px 模糊和文件夹/Dock/搜索统一材质仍属于平台或产品适配。
6. 本轮未取得用户手机的运行状态，不能承诺已解释该手机文件夹“更黑”的唯一原因，也不能宣布真机视觉完全一致。
