# 🚀 DesktopGo 使用说明

[简体中文](./USER_GUIDE.zh-CN.md) | [English](./USER_GUIDE.en.md)

适用平台：Windows 10 / Windows 11

DesktopGo 是一个面向 Windows 的桌面启动台，用来把自定义图标库、常用应用入口和 Everything 文件搜索收进一个统一入口里。

## 📦 1. 安装与启动

下载入口：

- 最新版本：<https://github.com/Aixbox/DesktopGo/releases/latest>
- 所有版本：<https://github.com/Aixbox/DesktopGo/releases>

安装步骤：

1. 下载并运行最新安装包，同一个安装包内已包含简体中文和英文安装资源。
2. 安装包每次启动都会先显示语言选择对话框，选择“中文(简体)”或“English”，之后的安装界面全部使用该语言；取消该对话框会直接退出安装，不会写入任何文件。
3. 如果电脑里还没有 Everything，建议在安装过程中保持“安装 Everything”选项开启。
4. 安装完成后，按 `Ctrl+Space` 呼出 DesktopGo。

首次启动时的默认值：

- 🌐 界面语言：跟随安装时选择的语言（简体中文或英文）
- 🎨 主题模式：跟随系统
- 🧱 图标尺寸：中等图标
- 🪟 窗口模式：中窗口
- 🏷️ 标题行数：两行标题
- 📌 Dock 栏：开启
- ⚡ 开机自启：开启
- ⌨️ 启动台快捷键：`Ctrl+Space`
- 🗂️ 图标库视图：列表

说明：

- 💡 主窗口失去焦点后会自动隐藏，这属于正常设计。

## 🧭 2. 快速上手

### ⌨️ 呼出与关闭

- 按 `Ctrl+Space` 呼出启动台。
- 按 `Esc` 可以关闭搜索面板、清空搜索，或在空搜索状态下关闭启动台。
- 启动台失去焦点时会自动隐藏。
- 也可以通过系统托盘图标重新显示启动台。

### 🖼️ 图标库

- 新安装的图标库默认为空，不会自动扫描整个桌面。
- 点击“导入图标”选择应用、快捷方式或文件；文件夹可以直接拖入启动台。
- 也可以直接把项目拖入启动台完成导入。
- 你可以长按图标拖动排序、分页整理、管理文件夹和 Dock。
- 右键启动台空白区域，可以快速调整图标大小、窗口大小、标题行数或进入编辑模式。

### 🔎 搜索文件与应用

- 顶部搜索框用于搜索。
- 默认搜索源是 Everything，可搜索文件、文件夹和应用。
- 输入内容后会自动打开搜索面板。
- 你可以在搜索面板顶部切换“Everything 搜索”和“图标库搜索”。

## 🧠 3. 搜索面板使用

### 🎛️ 基本操作

- 输入关键词后，搜索结果会显示在下方面板中。
- `ArrowDown` / `ArrowUp`：切换选中结果
- `Enter`：打开当前选中结果
- 双击结果：直接打开
- `Esc`：关闭搜索面板；若面板已关闭，则继续按会清空关键词或关闭启动台

### ⚙️ 搜索能力

- 支持搜索历史
- 支持筛选器，例如全部、文件、文件夹、程序、图片、视频等
- 支持排序
- 支持路径匹配、大小写匹配、正则表达式、全字匹配
- 支持右侧预览面板
- 支持大结果集虚拟滚动

### 🧾 当前默认搜索设置

- 实时搜索：开启
- 自动选中首个结果：开启
- 回车打开结果：开启
- 双击打开结果：开启
- 防抖时间：`120ms`
- 默认筛选器：全部
- 默认排序：路径升序
- 每页最大结果数：`50`
- 记住上次筛选器：开启
- 匹配路径：关闭
- 区分大小写：关闭
- 正则表达式：关闭
- 全字匹配：关闭
- 自动连接 Everything 运行时：开启

说明：

- 💡 “记住上次筛选器”默认是开启的，所以第一次是“全部”，之后会优先恢复你上次使用过的筛选器。

## 🧩 4. 图标整理与编辑

DesktopGo 使用统一图标库管理用户主动导入的应用、文件和文件夹。

可用能力：

- 拖拽排序
- 分页整理
- 文件夹管理
- Dock 常用入口
- 批量选择
- 隐藏图标
- 移出图标库（不会删除原始项目）

进入编辑方式：

- 右键启动台空白区域，点击“编辑图标”
- 或者在空白区域长按进入编辑模式

## ⚙️ 5. 设置页说明

设置页主要分为以下几个区域：

### 🌐 常规设置

- 界面语言
- 主题模式
- 标题行数
- Dock 栏显示开关
- 开机自启
- 启动台快捷键

快捷键说明：

- 默认是 `Ctrl+Space`
- 某些输入法或系统快捷键可能会拦截这个组合
- 如果你发现无法正常呼出，建议在设置里改成其他组合

### 🔍 搜索设置

你可以调整：

- 实时搜索
- 默认筛选器
- 默认排序
- 每页最大结果数
- 路径 / 大小写 / 正则 / 全字匹配
- 自动连接 Everything

### 🗂️ 图标库

图标库页用于导入和管理启动台项目。

支持内容：

- 所有“添加 / 导入图标”入口都会打开同一个添加图标弹窗
- 在弹窗中填写显示名称和目标路径；显示名称不会修改底层文件名
- 选择文件或文件夹后自动回填名称、路径并显示图标预览
- 展开“高级启动选项”可填写启动参数、工作目录和自定义图标
- 启动参数与工作目录写入 DesktopGo 管理的快捷方式，自定义图标独立缓存
- 查看和搜索图标
- 列表 / 宫格视图切换
- 按显示状态筛选
- 隐藏、显示或移出图标库
- AI 整理和布局重置

图标库只需要导入和管理项目，不需要额外配置存储目录或维护同步任务。

## 💾 6. 数据保存位置

DesktopGo 采用本地优先设计。

主要持久化内容：

- 常规设置：保存在 `settings.json`
- 启动台布局、搜索设置等状态：保存在本地 SQLite 数据库 `app_state.db`
- 图标库数据和图标缓存：保存在本地应用数据目录中

说明：

- DesktopGo 不依赖账号系统。
- 大多数设置、布局和搜索配置都只保存在当前电脑本地。

## 🛠️ 7. 常见问题

### ⌨️ 7.1 快捷键无效

优先检查：

- 是否被输入法占用
- 是否被系统快捷键占用
- 是否在设置里已经修改过快捷键

建议处理：

- 进入“设置 -> 打开启动台快捷键”，改成其他组合，例如 `Ctrl+Alt+Space`

### 🔎 7.2 搜索不可用

优先检查：

- 是否已安装 Everything
- Everything 是否已经启动
- DesktopGo 与 Everything 是否使用相同权限级别运行
- 安装 DesktopGo 时是否勾选了 Everything 安装选项

### 🪟 7.3 升级后默认值没有变化

这是正常的。

- 默认值只影响首次安装或本地没有对应设置时的情况
- 如果你之前已经保存过主题、窗口模式等设置，升级后会继续沿用你自己的旧值
