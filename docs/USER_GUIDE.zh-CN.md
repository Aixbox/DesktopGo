# 🚀 DesktopGo 使用说明

[简体中文](./USER_GUIDE.zh-CN.md) | [English](./USER_GUIDE.en.md)

适用平台：Windows 10 / Windows 11

DesktopGo 是一个面向 Windows 的桌面启动台，用来把桌面图标整理、常用应用入口和 Everything 文件搜索收进一个统一入口里。

## 📦 1. 安装与启动

下载入口：

- 最新版本：<https://github.com/Aixbox/DesktopGo/releases/latest>
- 所有版本：<https://github.com/Aixbox/DesktopGo/releases>

安装步骤：

1. 下载并运行最新安装包。
2. 如果电脑里还没有 Everything，建议在安装过程中保持“安装 Everything”选项开启。
3. 安装完成后，按 `Ctrl+Space` 呼出 DesktopGo。

首次启动时的默认值：

- 🌐 界面语言：简体中文
- 🎨 主题模式：跟随系统
- 🧱 图标尺寸：中等图标
- 🪟 窗口模式：中窗口
- 🏷️ 标题行数：两行标题
- 📌 Dock 栏：开启
- ⚡ 开机自启：开启
- ⌨️ 启动台快捷键：`Ctrl+Space`
- 🗂️ 图标管理视图：列表

说明：

- 💡 主窗口失去焦点后会自动隐藏，这属于正常设计。
- 💾 如果你之前已经保存过本地设置，后续升级不会自动覆盖你现有的个人配置。

## 🧭 2. 快速上手

### ⌨️ 呼出与关闭

- 按 `Ctrl+Space` 呼出启动台。
- 按 `Esc` 可以关闭搜索面板、清空搜索，或在空搜索状态下关闭启动台。
- 启动台失去焦点时会自动隐藏。
- 也可以通过系统托盘图标重新显示启动台。

### 🖼️ 桌面图标浏览

- 默认会读取桌面图标并以宫格方式展示。
- 你可以拖动图标调整顺序、分页整理、管理文件夹和 Dock。
- 右键启动台空白区域，可以快速调整：
- 🔹 图标大小
- 🔹 窗口大小
- 🔹 标题行数
- 🔹 进入“编辑图标”
- 🔹 打开设置

### 🔎 搜索文件与应用

- 顶部搜索框用于搜索。
- 默认搜索源是 Everything，可搜索文件、文件夹和应用。
- 输入内容后会自动打开搜索面板。
- 你可以在搜索面板顶部切换“Everything 搜索”和“桌面图标搜索”。

## 🧠 3. 搜索面板使用

### 🎛️ 基本操作

- 输入关键词后，搜索结果会显示在下方面板中。
- `ArrowDown` / `ArrowUp`：切换选中结果
- `Enter`：打开当前选中结果
- 双击结果：直接打开
- `Esc`：关闭搜索面板；若面板已关闭，则继续按会清空关键词或关闭启动台

### ⚙️ 搜索能力

- 支持搜索历史
- 支持筛选器，例如全部、文件、文件夹、程序、图片、视频等
- 支持排序
- 支持路径匹配、大小写匹配、正则表达式、全字匹配
- 支持右侧预览面板
- 支持大结果集虚拟滚动

### 🧾 当前默认搜索设置

- 实时搜索：开启
- 自动选中首个结果：开启
- 回车打开结果：开启
- 双击打开结果：开启
- 防抖时间：`120ms`
- 默认筛选器：全部
- 默认排序：路径升序
- 每页最大结果数：`50`
- 记住上次筛选器：开启
- 匹配路径：关闭
- 区分大小写：关闭
- 正则表达式：关闭
- 全字匹配：关闭
- 自动连接 Everything 运行时：开启

说明：

- 💡 “记住上次筛选器”默认是开启的，所以第一次是“全部”，之后会优先恢复你上次使用过的筛选器。

## 🧩 4. 图标整理与编辑

DesktopGo 除了展示桌面图标，还支持本地图标整理。

可用能力：

- 拖拽排序
- 分页整理
- 文件夹管理
- Dock 常用入口
- 批量选择
- 隐藏图标
- 删除图标记录

进入编辑方式：

- 右键启动台空白区域，点击“编辑图标”
- 或者在空白区域长按进入编辑模式

## ⚙️ 5. 设置页说明

设置页主要分为以下几个区域：

### 🌐 常规设置

- 界面语言
- 主题模式
- 标题行数
- Dock 栏显示开关
- 开机自启
- 启动台快捷键

快捷键说明：

- 默认是 `Ctrl+Space`
- 某些输入法或系统快捷键可能会拦截这个组合
- 如果你发现无法正常呼出，建议在设置里改成其他组合

### 🔍 搜索设置

你可以调整：

- 实时搜索
- 默认筛选器
- 默认排序
- 每页最大结果数
- 路径 / 大小写 / 正则 / 全字匹配
- 自动连接 Everything

### 🗂️ 图标管理

图标管理页主要用于维护“桌面来源”和“自定义应用来源”的图标快照。

支持内容：

- 查看图标列表
- 列表 / 宫格视图切换
- 自定义应用目录配置
- 增量同步
- 全量同步

同步说明：

- 增量同步：只补进新增项目，不处理旧记录，适合日常使用
- 全量同步：重新对照当前目录或桌面状态，补齐缺失项并清理失效记录，适合大整理后执行

### 🔄 更新

- 更新页会读取 GitHub Releases 的更新信息
- 可以在这里检查和安装更新

### ℹ️ 关于

- 可以查看版本号、应用标识符和 Tauri 版本
- 可以跳转 GitHub 仓库、Releases 和 Issues
- 可以复制诊断信息用于反馈问题

## 📁 6. `customapp` 自定义应用目录

DesktopGo 支持桌面之外的自定义应用入口。

默认规则：

- 如果你没有手动配置 `customAppDir`，默认目录是“可执行文件同级目录下的 `customapp/`”
- 如果目录不存在，程序会自动创建
- 当前只扫描一级目录，不递归扫描子目录

推荐使用方式：

1. 把常用应用的快捷方式、可执行文件或文件夹放进 `customapp` 目录。
2. 打开“设置 -> 图标管理”。
3. 确认当前生效目录正确。
4. 执行一次“增量同步”。

如果你更换了目录：

1. 在图标管理页输入新路径或选择文件夹。
2. 点击保存路径。
3. 再执行同步，让新目录内容进入启动台。

## 💾 7. 数据保存位置

DesktopGo 采用本地优先设计。

主要持久化内容：

- 常规设置：保存在 `settings.json`
- 启动台布局、搜索设置等状态：保存在本地 SQLite 数据库 `app_state.db`
- 图标快照和缓存：保存在本地应用数据目录中

说明：

- DesktopGo 不依赖账号系统。
- 大多数设置、布局和搜索配置都只保存在当前电脑本地。

## 🛠️ 8. 常见问题

### ⌨️ 8.1 快捷键无效

优先检查：

- 是否被输入法占用
- 是否被系统快捷键占用
- 是否在设置里已经修改过快捷键

建议处理：

- 进入“设置 -> 打开启动台快捷键”，改成其他组合，例如 `Ctrl+Alt+Space`

### 🔎 8.2 搜索不可用

优先检查：

- 是否已安装 Everything
- Everything 是否已经启动
- DesktopGo 与 Everything 是否使用相同权限级别运行
- 安装 DesktopGo 时是否勾选了 Everything 安装选项

### 📂 8.3 `customapp` 内容没有显示

优先检查：

- 当前生效目录是否正确
- 新文件是否真的放在被扫描的一级目录里
- 是否执行过同步

建议处理：

- 新增少量内容后执行“增量同步”
- 大幅整理目录后执行“全量同步”

### 🪟 8.4 升级后默认值没有变化

这是正常的。

- 默认值只影响首次安装或本地没有对应设置时的情况
- 如果你之前已经保存过主题、窗口模式等设置，升级后会继续沿用你自己的旧值
